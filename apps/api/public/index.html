Neelkanth API — webhook ingest only

This deployment builds and typechecks @neelkanth/api on push, and serves exactly one endpoint: /api/webhooks/fyers. It accepts broker callbacks and parks them in Redis — nothing else.

The control-plane API is a long-lived Fastify process (socket.io, BullMQ workers, MongoDB and Redis pools) and runs on its own host. It drains the webhook inbox from there.
